# DR-Visualize

## Project Title
An Explainable Deep Learning Framework for Early Diabetic Retinopathy Detection Using EfficientNet and Grad-CAM

## About
DR-Visualize is an academic MCA research project that aims to classify diabetic retinopathy severity from retinal fundus images using EfficientNet-B0 and provide visual explanations using Grad-CAM.

## Planned Dataset
APTOS 2019 Blindness Detection  
[Kaggle dataset](https://www.kaggle.com/competitions/aptos2019-blindness-detection/data)

The dataset will be downloaded when needed using the Kaggle API. The full dataset will not be stored in this repository.

## Planned Technologies
- Python
- Google Colab
- EfficientNet-B0
- Grad-CAM
- GitHub
